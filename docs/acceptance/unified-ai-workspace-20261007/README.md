## 实际页面验收

使用独立临时节点直接提供生产构建，没有 Vite 开发服务器。NAS 使用本地 HTTP WebDAV 服务和磁盘文件。AI 回答使用明确标注的合成验收服务。截图中只有人工构造的资料与对话，没有用户真实提示词、个人文件或认证信息。

1. 从空节点打开工作台：来源选择和空对话可用。
2. 添加允许 AI 的 NAS 文本：节点重新读取并保存副本，添加本身不调用回答服务。
3. 输入问题并点发送：确认弹窗显示接收节点、问题、资料与字节预算；确认后才创建任务。
4. 完成后检查回答归档和原引用。随后保存到 NAS，验证新文件与归档回答逐字节一致，原文件不被覆盖。
5. 在实际浏览器中创建浏览器原件，再从同一列表打开节点对话。两处历史没有自动合并或迁移。
6. 停止并重启节点：原回答、引用与新 NAS 文件仍可读；重新加载页面后的回答服务调用数为 **0**。
7. 从 NAS 文件预览点“向 AI 提问”：进入相同工作台，确认添加后出现资料和问题草稿，仍没有自动发送。
8. 检查 390 px 窄屏：资料、历史和输入区可用，页面内容宽度与视口宽度均为 390 px，没有横向溢出。
