# 做图页面（第 4 步）验收记录 — 2026-11-13

分支 `claude/image-studio-page-20261113`，基于第 3 步（develop `851468c3`）。界面稿：Claude Design 画布「Ryn 做图窗口」的画面 2、3。

## 做了什么

- `rynmesh/image_studio/web/`：`index.html`、`app.css`、`app.js`，原生 JS，不需要构建，没有内联脚本（网关的 CSP 不允许内联脚本）。所有用户文字都用 textContent 写进页面。
  - 新建：用途和尺寸（主图 1:1、海报 3:4、竖版 9:16、横幅 16:9、自定义 256–2048）、描述、图上文字、参考图（最多 3 张，可选文件、拖进来或粘贴，选好就上传，带缩略图和移除）、张数 1/2/4；提交前提示前面还有几个任务、大约多久开始。
  - 我的作品：全部 / 进行中 / 已完成；排队中（第几位、大约多久开始、取消）、生成中（已用时间、取消）、完成（缩略图、下载、再来一张、改这张）、没做出来（原因、重试）、已取消（重试）。有进行中的任务时每 3 秒刷新，否则每 15 秒。
  - 详情：大图、下载 PNG、再来一张、复制描述、描述/文字/尺寸/参考图/生成时间和用时；"在这张基础上改"把这张当参考图再提交，尺寸不变。
  - 打开详情再回来，左边写到一半的内容还在；轮询不会重画详情页（不会冲掉正在写的修改要求）。
  - 中英文：优先用 Ryn 传来的语言（`?lang=`），否则跟浏览器。Ryn 的页面窗口现在会带上 `lang`。
  - 对方电脑没装 Codex 或没登录时，页面顶部提示提交会失败。
  - 时间按开放方电脑的时钟换算，同事电脑时钟不准也不影响"已用时间"。
- 服务端：`index.html` 引用的脚本和样式自动带上内容哈希（`/app.js?v=…`），带版本号的文件长期缓存，不带的每次重新验证。验证时发现原来的写法会让旧脚本缓存一年，已修正。
- 打包：`pyproject.toml` 的 package-data 加了 `rynmesh.image_studio = ["web/*"]`（打包脚本 `--collect-data rynmesh` 依赖它）。
