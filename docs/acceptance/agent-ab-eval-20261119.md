- `【评测】01-新版-1`（14:55:44）用时 136.5 秒，评分为正确。已生成并回读验证 margin.xlsx，保留两组原始数据及公司汇总。 公司营业利润率 = 120 ÷ 1000 = 12.00%，已设为 Excel 百分比格式。 sales.csv 未修改。 Excel 数值单元格为 12%，两组原数据及公司汇总正确。
- `【评测】01-旧版-1`（15:22:15）用时 73.2 秒，评分为正确。已生成 margin.xlsx，保留两组原始数据及公司汇总。 公司营业利润率：120 ÷ 1000 = 12.00%，已验证 Excel 公式和百分比格式。 Excel 数值单元格为 12%，两组原数据及公司汇总正确。

## 新版较差或持平的地方

- 新版平均 104.7 秒，旧版平均 59.5 秒。22 组配对中新版全部更慢，中位差 36.7 秒。
- 新版平均 137,811 Token，旧版平均 99,311 Token。平均模型调用约 4.32 次与 4.18 次。
- 10 道适用题在两版的两次运行中都正确，改需求、自恢复、识别缺失文件、代码审查等未观察到准确性提升。第 7 题新版第一次也未要求确认报告。
- 预检期间曾出现 CLI 模型显示为裸 ID、强度选项暂时缺失。通过 Ryn 界面刷新接入并复核后才继续提交。该现象和目录保存故障均单独记录，未计为正式任务失败。

## 预检与恢复

首次预检在系统盘空间不足时返回 HTTP 409 `agent_storage_limit`，当时没有提交题目。磁盘恢复时归档了 244 个遗留 Ryn 临时文件，约 491 MiB，并逐一核对哈希。复测时系统盘空间已清出，工作目录保存和回读通过。通过模型页面重新接入既有 Codex CLI 后，界面恢复显示轻度选项。

结束后旧版进程和评测调试监听均为 0。新版 0.9.1 已在原桌面会话普通启动，节点和公司插件健康检查均为 HTTP 200。已恢复使用已保存记忆，自动提取保持关闭。手动偏好、默认工作目录和默认模型未改，临时请求上限已恢复自动。恢复后的 17 个 Ryn 快捷方式、目标及参数和 11 条文件打开命令与评测前一致。

旧版便携副本和独立历史已保留。评测没有修改任何产品代码，没有推送或发布。

## 结论

新版正确率与一次完成率均为 21/22（95.5%），旧版均为 20/22（90.9%）。两版假完成和失败均为 0。正确数仅差一个模糊请求样本，每题仅运行两次，无法据此确认整体质量提升。耗时在 22 组配对中方向一致，并伴随更高 Token 用量，支持新版在本套题和本机配置下效率较低的结论。运行顺序按每题新、旧、旧、新分批，单次评测中系统负载与上游时延未单独控制，数据不足以将差距归因到单项改动。
