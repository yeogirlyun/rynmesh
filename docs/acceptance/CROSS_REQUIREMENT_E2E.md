# 五项用户需求跨需求端到端验收

日期：2026-09-04

平台：Windows x86_64，三个互不复用的干净 `RYNMESH_HOME`

结论：连续 3 次通过，每轮 12/12 步通过

## 验收方法

运行 [run_five_user_requirements_journey.py](../../qa/run_five_user_requirements_journey.py)，
每轮启动真实本地节点进程并只通过 HTTP 公共接口操作。三轮各自从空目录开始，不复用
模型、运行时、数据库、配置或好友状态。模型安装使用正式清单中的
Qwen2.5-0.5B Q4 与原生 llama.cpp 运行时，包含真实下载、SHA-256 校验、启动和推理。

## 12 步验收旅程

1. 干净节点启动并通过健康检查。
2. 零配置获取真实推荐，达到可用内容门槛。
3. 打开、收藏并记录首个内容的阅读进度。
4. 一键下载/安装真实本地模型并得到首个真实回答。
5. Ask Ryn 使用当前内容上下文回答，并返回可打开引用。
6. 停止模型与节点后重启；模型自动恢复，历史运行和阅读进度仍存在。
7. 导入有效 PDF，在 Library 上下文中提问并得到引用。
8. 两个干净节点通过 invite review/join 建立 active 关系。
9. 发送文字、小附件和 Library 内容卡片，三项均 delivered。
10. 确认内容正文未预取；用户明确确认后拉取，SHA-256 一致，只导入一次。
11. 撤销关系，下一次好友请求被拒绝。
12. 两个节点分别导出数据，确认不含私密标记和秘密字段。

## 判定

- 三轮均从干净目录完成真实下载和安装，不以 fixture 或预置缓存替代。
- 三轮首次内容与来源数均达到门槛；外部来源健康数允许随网络状态波动。
- 三轮均证明安装后的模型可作为 Ask Ryn 的本机 target，并可在节点重启后恢复。
- 三轮均证明内容卡片正文在确认前不存在，确认后完整性可验证且重复拉取不重复导入。
- 三轮均证明 revoke 后下一次请求 fail closed，隐私导出不泄露秘密。
