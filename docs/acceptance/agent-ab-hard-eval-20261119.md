## 结论与恢复

按约定，只把至少 20 分的差距或一边完成、另一边失败或假完成记为明显能力差异。本次四题均无此类差异，八次运行无失败、假完成或超时。新版四题合计 25 分 17 秒、69 次模型调用，旧版 16 分 17 秒、51 次调用。第 1 题和第 3 题是本次新版耗时落后的主要来源。每题每版仅有一次，耗时结论限于本次运行。

生成种子为 20261119。第 1 题共 24 个 Python 文件、4,989 行。首题发送至末题终态约 44 分钟，包含版本轮换与重启。
旧版第 3 题重开后模型选择器短暂只显示模型 ID。通过打开任务历史读取的任务详情核对，记录仍为 gpt-6.1-sol、medium。界面探测只读取元数据，题面和续做均经同一对话输入框发送。
首次新版便携启动的原生日志写到了系统默认 Ryn 日志目录。第 3 题重启起将便携原生日志重定向至评测目录，保留已有日志。两便携副本均以回环地址监听，未配置公司插件或注册中心。
两便携版本已正常退出，便携进程、监听和测试工程进程残留均为 0。正式版 E:/Apps/Ryn 已在原桌面会话正常启动，节点和公司插件健康检查均返回 HTTP 200。17 个 Ryn 快捷方式的名称、目标和参数，以及 11 条文件打开命令均已核对恢复。未修改产品代码、未推送、未发布。
