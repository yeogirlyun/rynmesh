# Agent test helpers and fixtures

The Python and JavaScript helpers support offline regression tests for task controls, permissions, collection, normalization and reference integration. Historical JSON inputs required by these tests preserve the original business outcomes; test success describes the parser or runtime assertion, not model-quality acceptance.

Private LAN addresses in published fixtures are replaced consistently with RFC 5737 documentation addresses. Original local audit records are retained outside the submitted tree. Runtime traces, pairing capabilities, machine configuration and unpublished acceptance runs are excluded.
