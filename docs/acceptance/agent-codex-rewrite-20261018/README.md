# Ryn Agent 内核重写验收记录

本目录收录 2026-10-18 的开发说明与独立验收报告，2026-10-19 整理为公开交付副本。
报告中的结论、源码指纹和测试数均属于当时受核快照，不自动代表后续源码或本次上传重新验收。

## 实际改动

- 在 Ryn 自有循环接通分层提示词、历史配对、模型事件、工具路由和明确的回合继续/结束判定。
- 工具参数错误作为对应调用的反馈返回；完整可信只读条目可提前执行，结果按请求顺序回写。
- 写操作等待整条响应接受，继续使用现有权限、精确批准、operation ledger 和执行回执。
- 补齐压缩完整性、取消/追加输入、旧会话恢复，以及应用已提交但响应不确定时的收据恢复。
- 恢复只查询原 operation 的已存在收据，验证原命令与 preview 后结清 consumer intent，避免重发业务写入。

实现与原有能力的区分、参考机制及接线范围见 [机制说明](MECHANISMS.md)；七项合同见 [计划](PLAN.md)。

## 最终验收与历史失败

[第三轮独立验收](INDEPENDENT-REVIEW-003.md) 的结论为七项全部 PASS，限“关键自动化＋3–5 个真实任务”的约定范围。
该轮实际运行 141 项关键回归、24 项新增收据边界探针；另有重叠的 28 项审计，不能相加宣称独立覆盖量。
真实任务包含 GLM API 与 Antigravity/Gemini 的项目查找、文件修改验证、错误纠正及 Desk 应用闭环。
真实任务跨越既有修补快照；第三轮没有重新收费推理，不能写成全部任务在最终 hash 下重跑。

[第二轮 FAIL 报告](INDEPENDENT-REVIEW-002.md) 保留原结论：应用提交后的无效响应曾被误记为未执行，
找回收据后还会遗留 consumer pending。第三轮通过真实加密传输故障探针确认两项关闭，原票未重复创建，后续新任务可继续。
比较任务的全部 12 次尝试保留 8 PASS / 4 FAIL 及慢样本，不据有限样本宣称整体提速。
早期临时目录清理失败、旧断言失败及固定 12 KB 容量反例也保留，不改写成全仓全绿。
