# 插件页点击白屏与 EPR/VAT 链接 · 2026-11-05

用户报告两处问题：Dashboard 插件页一点击或拖动窗口就白屏，像整页重新加载；公司列表里的「新增EPR和VAT税号」点了没有反应。

| 仓库 | 分支 | 提交 |
| --- | --- | --- |
| Ryn | `claude/plugin-vat-window-20261105` | `1202251` 新窗口放行 EPR/VAT 列表 |
| 公司插件 | `claude/plugin-focus-vat-20261105` | `a44894a` 聚焦不再隐藏页面；`6e79ec4` 公司列表固定使用有 VAT 权限的 OA 账号 |

## 原因

1. **白屏**：公司插件 11-04 加入的账号核对（`companyAccount.ts`）在每次 `focus` 时隐藏整个页面、断开并重连账号事件流，再等插件服务向宿主核对账号。点进页面和激活窗口都会触发 `focus`。核对与每秒一次的宿主监测共用一把锁，单次超时 7 秒，宿主稍慢页面就长时间空白；核对失败时账号被置空，工作区整体卸载，恢复后重新挂载，Dashboard 框架随之重新加载。
2. **链接无反应**：OA 页面用 `target="_blank"` 打开 `companyVat.php`。Ryn 主窗口只放行发票 PDF 和带数字 id 的公司详情，其余新窗口一律拒绝。
3. **权限**：OA 公司列表把自身 `user` 参数原样带入 VAT 链接；无 VAT 权限的账号打开 `companyVat.php` 得到空页面（实测 0 字节）。

## 改动

- 插件：事件流在线且 30 秒内确认过账号版本（事件流每 15 秒推送一次完整账号，变化即时推送）时，`focus` 不再隐藏或重新核对。事件流关闭或静默超过 30 秒、宿主无法确认账号、页面从隐藏恢复可见时，仍先隐藏再核对。这是对需求「获得焦点时先核对 version」的实现调整：在线事件流的最近确认视为本次核对。
- 插件：公司列表 iframe 固定使用有 VAT 权限的 OA 账号，已登记在 `gp-finance/migration-patches.json`。
- Ryn：`companyVat.php?user=<单个普通账号名>` 打开到可复用的独立窗口，窗口内只能在 VAT 列表与店铺税费页之间跳转，没有本地命令权限。
