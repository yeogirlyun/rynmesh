# 切换页面秒出：插件页保活、Agent 记录与企业微信会话列表本机缓存 · 2026-11-05

用户反馈：每次打开 Ryn、切换页面都像重新加载，Gshopper、企业微信对话、Agent 记录尤其卡手；要求打开即显示。用户确认 Agent 对话内容也存本机，以便点开任务也秒出。

| Ryn | `claude/instant-pages-20261105` | `8351054` Agent 记录本机加密缓存；`d2ab892` 插件页保活 |
| 公司插件 | `claude/wecom-instant-list-20261105` | `f6d15d2` 企业微信会话列表本机缓存、隐藏时暂停刷新 |

## 原因

1. **插件页**：离开插件页时 iframe 被销毁。再次进入要依次读插件清单、确认插件服务、探测端口、重新加载约 900 KB 的插件程序、隐藏整页核对公司账号、再拉数据。Gshopper 工作台、Dashboard、联盟营销是三个独立插件，互相切换也各自从头加载；Dashboard 内层的旧版页面和财务身份核验一并丢失。
2. **企业微信**：聊天内容有本机缓存，但会话列表没有。每次进入先清空列表和当前会话，等本机企业微信状态和会话两个接口先后返回才显示。
3. **Agent 记录**：任务列表只在内存里保留点开过的最多 20 条，回到页面时列表先少后多；重启后为空，直到本机服务返回。

## 改动

- Ryn：打开过的插件页常驻（每个窗口最多 3 个）。切走时保持原尺寸移出可视区、不可交互、不进入无障碍树；切回原样显示，不重新加载、不重新排版。用 `ryn.plugin.visibility` 消息告知插件可见状态。复用上次插件清单，后台刷新；清单内容未变不会重载页面；插件被停用或删除时关闭其常驻页。
- Ryn：Agent 完整任务列表在切换页面间保留在内存；任务列表和最近打开的 30 个对话存本机 IndexedDB，用不可导出的 AES-GCM 密钥加密（与私有 AI 聊天相同）。不支持 IndexedDB 或 Web Crypto 时不存，绝不明文落盘。启动时在等待本机服务的同时读入，打开页面即显示，本机服务返回后替换。运行中的任务最多每 1.5 秒写一次，窗口隐藏时立即写；删除任务同时删除本机副本。
- 公司插件：按企业微信账号保存会话列表（最多 500 条）、上次打开的会话；进入时先显示，再后台刷新。换企业微信账号只显示该账号自己的副本。新键都以 `ryn.company.wecom.` 开头，公司账号变化时随其他公司缓存一并清除。插件页被 Ryn 隐藏或窗口最小化时暂停每 3 秒一次的刷新，重新显示时立即刷新。

## 验证

- Ryn 新增测试 14 项全部通过：加密存储 7 项（密文不含原文、频繁更新只写最新值、只保留 30 个、删除后不被排队写回、关闭时不写、重启恢复且不覆盖更新的数据）、Agent 重启 2 项（本机服务未响应时已显示列表和对话；本机服务返回后替换旧副本）、插件页保活 5 项（切回是同一 iframe、插件之间切换不重载、清单刷新不重载、超过 3 个关闭最早的、插件停用后关闭）。
- Ryn 相关 38 个测试文件串行运行：410 项中 408 项通过。2 项失败与本次无关：`can select autonomous workstation execution…` 用 develop 原版代码同样失败；`keeps a pending followup scoped…` 在本机 5 秒超时临界，原版代码 3 次中失败 1 次、本分支 3 次中失败 1 次，耗时相当。TypeScript 检查通过。
- 本机并发运行测试会耗尽 6 GB 内存，出现大量超时失败；须用 `--maxWorkers=1 --no-file-parallelism`。
- 公司插件新增 3 项测试通过；其中 2 项用 develop 原版代码运行失败（证明测试覆盖新行为），第 3 项为不串账号的防回归检查。原有 `CompanyFinanceApp`（2 项）与 `WeComLocalChatAnalysisPanel`（1 项）失败在原版代码上完全相同。TypeScript 检查只剩 develop 原有的 `AffiliateGuidePage` 报错。
- 真实浏览器（内置 Chromium，1280×800）：宿主页使用与 `personal.css` 完全相同的样式和切换方式，载入另一端口的跨域插件页。切走 1.5 秒再切回：插件启动标识不变（未重新加载）、滚动位置 1234 保留、页面内状态保留、尺寸保持 1080×800 且 0 次 resize；隐藏时点击落在宿主内容上而非插件；插件先后收到 `visible:false` 和 `visible:true`。
