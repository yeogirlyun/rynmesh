# Ryn 本地编辑窗口 · Windows · 2026-10-15

Craft 编辑器的桌面入口已从系统浏览器改为 Ryn 的独立 WebView2 窗口。12 个现有固定 WebAssembly 构建沿用已下载的程序包、版本、SHA-256 和上游许可；本次没有安装上游原生二进制，也没有改变 FilmCraft 无 Web 构建的状态。浏览器访问 Ryn 时仍使用普通浏览器窗口。

每个插件使用独立源站、独立窗口和独立的本机编辑器存储目录，按节点及插件区分。再次打开会聚焦已有窗口，保留其中的文档。关闭编辑器不会退出 Ryn。卸载程序包时不会删除这些编辑器数据。原有外部浏览器存储没有被移动或清理。

桌面入口仍先走原启动预览与确认 ticket，Rust 只接受固定插件 ID，并向本机控制接口核验已安装、已启用和运行状态。编辑器窗口不授予 Tauri 能力；所有自定义原生命令还由主窗口标签进行统一把关。导航限于该编辑器自身源站，新窗口请求被拒绝，现有静态服务 CSP 保留。导出使用用户选择目标的 Windows“另存为”对话框；本地文件导入使用系统文件选择器。

## 已验证

- 插件前端 14 项测试通过，包括桌面入口不调用外部浏览器、用户确认之前不启动、窗口失败时不显示成功，以及中英文资源一致性。默认 fork 测试 worker 启动超时，改用单个 threads worker 后 14 项全部通过。
- Rust 原生入口 3 项测试通过，覆盖固定源站、阻止跳转控制 API/其他插件/外部站点、禁止编辑器原生命令及存储目录标识校验。
- TypeScript/Vite 构建、Windows release 桌面构建通过。此轮使用 `--no-bundle` 更新本机 `Ryn.exe`，没有生成新安装器，也没有重打包或替换后端。
- 通过实际桌面按钮与启动确认，在 Ryn 进程中打开 PDF、Word、Excel、PPT；截图均包含 Ryn 的原生窗口标题栏。Word 进入空白文档，Excel 显示空白工作簿，PPT 显示上游自带 Northern Lights 示例。
- PDF 新建空白页 → 原生另存为 → 实际文件解析 → 系统文件选择器重新打开，通过。输出 522 字节、1 页、612 × 792 pt，SHA-256 见 [native-pdf-export.json](native-pdf-export.json)。这不是内容修改、复杂格式或所有文档往返的完整验收。
- 再次点击 PDF 的打开入口，仍使用原窗口 ID，已导入的文档标签保留。关闭 Word 后 Ryn 主窗口与 PDF 窗口仍存在，见 [native-ui-checks.json](native-ui-checks.json)。
- 本机节点身份、默认四件套选择和 16 个已安装/启用条目保留；后端二进制哈希未变，旧桌面程序保留了回退副本，见 [installed-result.json](installed-result.json)。
