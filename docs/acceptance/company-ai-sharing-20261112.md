## 改了什么

**A. 公司通道放开 CLI**
- `rynmesh/llm_package/routes.py`：`provider_model_status` 不再排除 Codex、Claude、Antigravity。CLI 以「默认模型」整体共享。
- 共享出去的 CLI 仍是纯文本：提供方只返回文字和工具调用建议，命令在调用方自己的电脑上执行。
- Claude CLI 原来没有模型绑定，无法通过公司通道的校验。新增只用于公司通道的默认模型绑定（`cli_binding.py` 的 `CLIDefaultModelBinding`）；它在家庭组里的行为没有变。
- `docs/PEER_PROVIDERS.md` 已同步，去掉了「CLI 不能共享」的说法。

**B. AI 池子里的「公司同事」勾选**
- 每个本机模型一行一个独立勾选，和「个人空间 / 好友」互不影响，底层调用现有的 `/api/local/peer-providers/{plugin_id}/publish`。
- 只在三个条件同时满足时出现：装了公司插件并已登录、本机已绑定、公司中心说当前用户是发布人。其他人看不到这个勾选。
- 顺带修正：公司中心的工作台接口读不到、退回到目录数据时，旧代码把当前用户写成「可发布」，现在改为「不可发布」，避免出现点了会报错的开关。

**C. 「公司共享」分组**
- AI 池子和 Agent 的模型选择器都新增「公司共享」分组，显示提供人的名字（来自公司目录）和在线 / 离线。

**D. 用量按人统计（只在提供方本机）**
- `model_usage.py`：共享用量下新增按调用设备的记录（`by_peer`，保留 30 天）。只记公司通道的调用；家庭组和好友的统计方式不变。
- 旧的 `model-usage.json` 不需要迁移，照常读取，原有数字不变。
- AI 池子新增「公司同事用量」：按人、按模型列出今天和近 30 天的请求数和 token 数。只在本机有公司共享模型（或已有记录）时显示。
- 新增只读接口 `GET /api/local/llm/models/usage/company`。没有限额，没有上报。

**E. 公司插件**
- 已核实：插件「AI 共享」页的 CLI 开关调用 `models.share`，在 Ryn 里对应的是家庭组那套个人共享，不是公司通道。已删除。
- 同页的模型发布开关和同事模型列表也已删除，只保留一个「打开 Ryn AI 池子」按钮（Ryn 新增 `models.manage` 入口）。旧版 Ryn 不支持跳转时，按钮会提示到 Ryn 的「模型」页面设置。

## 同事的实际连接流程

同事装好公司插件并用企业微信登录后，**不需要再扫码，也不需要点「连接」**：Ryn 后台每 30 秒用插件已有的登录凭据向公司中心换取 `peer.connect` 会话（公司中心已实现这种换取方式），然后自动绑定本机并读取目录。「公司共享」分组随后出现在模型列表里。只有插件登录本身失效时才需要重新登录。

## 已知限制

- 每台提供方电脑只能看到自己共享出去的那部分用量，看不到全公司汇总。
- 用量按设备记录，再通过公司目录对应到人。同事离职或设备解绑后，旧记录显示记录当时保存的名字；从未取到名字的显示「未知设备」加设备号前 8 位。
- 「今天」按 UTC 日期切换（北京时间早上 8 点），和 Ryn 现有用量卡片一致。
- 公司通道里 CLI 只共享默认模型，同事不能在 Codex 的多个模型之间选择（公司目录不带 CLI 的模型清单，改它需要动公司中心）。
- Claude CLI 本身只支持对话，不支持 Agent 工具，共享出去也一样。
- 模型原有的「共享 token 每日上限」如果之前设置过，对公司同事的调用同样生效；本次没有新增任何限额。
- 公司插件主工作区（`codex/local-only-overbroad-snapshot-20261102` 分支）里有别人未提交的 `CompanyFinanceApp.tsx` 改动，以后合并时会和本次删掉的那一段冲突，需要保留「删除开关」的结果。
- Ryn 仍保留 `models.share` 这个插件入口，旧版插件可继续调用。

## 上线后的切换步骤

1. 在公司中心配置发布人名单（老板和管理员的 userid），重启公司中心。
2. 老板和管理员装新版 Ryn，同事装新版 Ryn 和新版公司插件。
3. 老板在 Ryn 的 AI 池子里，对要共享的模型勾选「公司同事」。
4. 找一两位同事试用：在模型选择器的「公司共享」分组里选模型，发一条消息，再让 Agent 执行一次工具，确认命令是在同事自己的电脑上执行的。
5. 老板在 AI 池子的「公司同事用量」里确认看到了这几位同事。
6. 确认没问题后，把同事从家庭组里移出。老板自己的家庭组设备照常使用。

回退：取消「公司同事」勾选即可立刻停止共享；在移出家庭组之前，同事原来的用法不受影响。
