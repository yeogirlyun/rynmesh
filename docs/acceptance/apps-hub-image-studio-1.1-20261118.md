## 范围

需求拆成 21 个小项，由 Codex 工人领取，逐项验收后合入集成分支。

**「应用」入口（A01–A10、A13）**

- 一个「应用」入口，三个页签：我的应用 / 同事共享 / 发现。原来的「开放的页面」列表删除，旧地址跳到「同事共享」。
- 置顶：任何本机应用或同事共享的应用都可以用星标置顶到侧栏（`/api/local/apps/pins`，最多 30 个）；首次使用自动置顶公司应用。
- 同事共享：按应用分组，显示谁在线、排队和预计等待；自己的另一台电脑也会列出；可以换一台电脑打开。
- 应用详情页：使用 / 共享给同事 / 版本与更新。
- 发现：公开插件和办公应用的安装、更新集中在一处；`/settings/plugins` 跳到这里。

**做图 1.1（B01–B09、B11）**

- 场景模板（横幅、商品主图、海报、详情页头图、社媒配图）和每个场景的常用尺寸。
- 主标题、副标题、角标分栏填写。
- 附图分身份：素材（商品出现在成品里）/ 风格参考，一次最多 5 张。
- 素材库：个人素材和公共素材（电脑主人管理）。
- 从成品派生其它尺寸（一次最多 6 个）；只换背景、只改文字、换个角度；透明底 PNG。
- 很扁或很长的尺寸里商品和文字保持完整。
- 出图失败的原始原因只给电脑主人看。

没做、等老板决定：公司中心的共享应用目录（要改生产库并部署中心服务）、精确抠图合成。

## 验证

- 后端：`tests/test_image_studio*.py` 与 `tests/test_public_plugins.py` 93 项通过；`tests/test_app_pins.py`、`tests/test_node_sites.py`、`tests/test_node_sites_shared_apps.py` 32 项通过。
- 前端：应用相关 8 个测试文件、做图页面 2 个测试文件、`tsc -b` 通过。全量前端测试在收尾项上跑过一次：212 个文件里 4 个失败，`RynAgentSending`、`RynAgentGuidance` 在集成起点就失败，`Friends` 单跑通过；没有在最终提交上重跑全量。
- 真实出图（宿主机已登录的 Codex，临时任务库，5 张全部成功，每张 43–64 秒）：
  1. 一张手机产品照作为素材；
  2. 用它出 1920×600 横幅，科技风，三段中文文案一字不差，手机完整；
  3. 从横幅派生 1080×1080，同一个设计重新排版；
  4. 只换背景，手机和文字不变；
  5. 透明底单图，成品带透明通道（alpha 0–255）。
- 发布后独立复核（无凭据访问）：线上 `plugins/catalog.json` 签名用主程序内置公钥验证通过，`image-studio` 版本 `1.1.0`、源码提交 `2f689c0b`；从 Release 下载的 ZIP 大小、SHA-256 与目录一致；包内 23 个文件逐个哈希与目录清单一致；主程序 latest 仍为 `v0.9.1`。
