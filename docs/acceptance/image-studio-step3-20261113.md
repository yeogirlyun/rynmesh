# 做图后台（第 3 步）验收记录 — 2026-11-13

分支 `claude/image-studio-20261113`，基于 develop `cb8ecc3`。说明见 [IMAGE_STUDIO.md](../IMAGE_STUDIO.md)。

## 做了什么

- `rynmesh/image_studio/`：
  - 出图：用本机登录的 Codex 原生出图，可带参考图（作为回合图片输入，并让工具用 `num_last_images_to_include`），失败按原因分类。
  - 尺寸：Codex 固定按"自动"尺寸出图，所以把比例写进描述（如"竖版，宽高比 9:16（1024×1820 像素）"），出图后居中裁切、缩放到准确像素，另存 384 像素 JPEG 缩略图。
  - 队列：SQLite，一次一张，排第几和预计等待，取消（排队中和生成中都能取消）、重试、开放者提前，重启后接着做（同一任务最多 3 次）。每人最多 20 个进行中的任务，作品保留 90 天，未用的上传 1 天后清理。
  - 同事接口：作为内置节点网页 `image-studio` 运行在 Ryn 进程里，身份只来自节点网页通道；历史按人（成员）而不是按设备；别人的任务一律 404。
  - 开放者接口：状态、队列、每人用量、取消、提前。
- 节点网页支持内置网页（不占端口，不需要令牌，检查和开关与普通网页相同）。
- 首次启动时把"做图"登记为关闭状态，开放者在"开放的页面"里打开。
