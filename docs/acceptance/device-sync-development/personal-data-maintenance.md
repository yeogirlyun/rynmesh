# 个人数据维护：范围与开发验证

此记录对应 G08 和 SYNC13，仍为开发中。现有设置页的隐私入口只覆盖阅读记录、推荐画像、缓存、审计和首次使用状态；新增功能不能据此宣称已支持完整导出或擦除。

## 已实现的来源事务

`ask_ryn/privacy.py::ConversationPrivacy` 是内部步骤，尚未连接设置页或新的 HTTP 路由。它不启用会话同步，也不执行网络请求。

- 审核令牌绑定当前来源快照，包括会话、未发送草稿、冲突/恢复项和任务记录。审核后出现新内容时拒绝旧操作。
- 原任务处于排队、发送、运行或未知状态时先等待确认；此步骤不执行 GPU 取消、不改变订单结算。
- 同一原子提交清除普通会话、独立恢复副本、本机草稿、同步候选和已结束任务的正文。保留删除标记、迁移摘要及任务身份/请求指纹，阻止旧浏览器导入、旧设备投递或同一请求重试重新生成内容。
- 清除凭据保存在加密来源文件中。响应丢失或重启后重试返回原凭据，后来新建的会话和草稿保持不变。
- 只处理已知来源数据范围；顶层未知扩展保持原样，未来版本不覆盖。返回值明确为 `conversation_source`，远端确认固定为否。

相关测试 **61 passed / 1 warning，11.01 秒**，包含新增 16 项来源擦除测试及现有会话存储、任务、同步测试。使用临时目录、真实加密和原子文件写入，验证并发版本变化、写入失败重试、重启、旧投递、独立恢复副本及原任务重试不再次派发。没有用此结果代替界面验收。

测试也明确证明：此内部步骤之后 `history.json.migrated` 仍存在。因此必须完成下面的协调流程后才能提供“个人数据已清除”的结果。

## 需要纳入用户审核的范围

| 数据 | 当前实现/位置 | 后续导出与擦除要求 |
|---|---|---|
| 阅读与推荐 | 现有 consumption、推荐画像、首次使用服务 | 复用现有接口；同步来源、迁移备份及解释记录一并列明 |
| Ask Ryn 来源 | `ask-ryn/history.json`、来源恢复项 | 导出复用 `export_owner` 的允许字段；擦除使用上述原子步骤 |
| 会话同步副本 | `device-sync/replica.json` | 来源擦除提交后同步删除标记，清掉副本正文；失败保留待处理状态，不宣称完成 |
| 设备关系与远端结果 | `device-sync/pairings.json` | 邀请凭证、密钥不默认导出；离线、暂停、移除设备的旧副本不能宣称已收回；分别显示确认状态 |
| 迁移备份与中断写入副本 | 已知的 `.migrated`、`.v2.migrated` 及原子写入临时文件 | 明确列入审核，仅处理已核对路径和内容版本；中断后能重试，不递归删除整个用户目录 |
| 搜索派生数据 | `local-search/index.json` 及内存索引 | 来源清除后协调重建，等待正在执行的旧重建退出，防止旧快照重新落盘 |
| 旧浏览器会话 | `llmConversationStore.ts` 中的 IndexedDB/会话内存 | 当前浏览器清除单独确认；其他浏览器、浏览器备份不能由节点声称已删除 |
| 原始任务与结算 | `llm/consumer-orders`、结果保留接口 | 区分正文/结果与防重复结算记录；不得直接删目录导致任务身份或账务丢失 |
| 好友分享与导入内容 | `friends/state.json`、导入库 | 导出筛选公开关系字段，排除 secrets/邀请能力；清理独立保存副本与撤销关系分别说明 |
| 好友动态 | `friend-feed/state.json` | 草稿、发布快照、订阅和接收内容明确区分；停止相应后台接收后再清理 |
| 离线阅读 | `offline-reading/state.json`、下载目录 | 复用已审核的清理接口，包含正文、图片及检查点；旧下载任务不能重新写回 |

好友关系 `state.json` 是受私有文件权限保护的 JSON，不能将其描述为加密会话容器。其历史 `secrets.json` 及迁移备份也属于需要明确处理的凭证范围。

## 下一步协调流程

1. 在 Owner 设置入口显示导出/清除范围、数量及保留项，不默认导出密钥、邀请能力或 Provider 凭证。
2. 以一个稳定操作身份保存审核结果和分步进度。来源提交、副本清理、备份处理、索引和浏览器确认分别记录；部分失败保留重试入口，已完成步骤不重复清除新内容。
3. 遵守设备配对 → 来源 → 副本的现有锁顺序；索引重建和网络调用不得放在来源锁内，避免和读取来源的后台任务互相等待。
4. 验证端到端流程：审核后编辑、取消、磁盘失败、重启、旧消息、离线/移除设备、清除后再次使用。只有本地范围全部完成才显示本地完成；远端须另有真实确认。

上述完整协调流程、导出下载和设置页实测尚未完成，G08/SYNC13 状态不变。
