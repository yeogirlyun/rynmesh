# 个人数据维护：范围与开发验证

此记录对应 G08 和 SYNC13，仍为开发中。现有设置页的隐私入口只覆盖阅读记录、推荐画像、缓存、审计和首次使用状态；新增功能不能据此宣称已支持完整导出或擦除。

## 已实现的来源事务

`ask_ryn/privacy.py::ConversationPrivacy` 是内部步骤，尚未连接设置页或新的 HTTP 路由。它不启用会话同步，也不执行网络请求。

- 审核令牌绑定当前来源快照，包括会话、未发送草稿、冲突/恢复项和任务记录。审核后出现新内容时拒绝旧操作。
- 原任务处于排队、发送、运行或未知状态时先等待确认；此步骤不执行 GPU 取消、不改变订单结算。
- 同一原子提交清除普通会话、独立恢复副本、本机草稿、同步候选和已结束任务的正文。保留删除标记、迁移摘要及任务身份/请求指纹，阻止旧浏览器导入、旧设备投递或同一请求重试重新生成内容。
- 清除凭据保存在加密来源文件中。响应丢失或重启后重试返回原凭据，后来新建的会话和草稿保持不变。
- 只处理已知来源数据范围；顶层未知扩展保持原样，未来版本不覆盖。返回值明确为 `conversation_source`，远端确认固定为否。

相关测试 **61 passed / 1 warning，11.01 秒**，包含新增 16 项来源擦除测试及现有会话存储、任务、同步测试。使用临时目录、真实加密和原子文件写入，验证并发版本变化、写入失败重试、重启、旧投递、独立恢复副本及原任务重试不再次派发。没有用此结果代替界面验收。

随后后端全量 **1287 passed / 29 skipped / 5 warnings，225.52 秒**；产品代码为 `5198d80`，运行期间保持不变。

测试也明确证明：此内部步骤之后 `history.json.migrated` 仍存在。因此必须完成下面的协调流程后才能提供“个人数据已清除”的结果。

## 需要纳入用户审核的范围

| 数据 | 当前实现/位置 | 后续导出与擦除要求 |
|---|---|---|
| 阅读与推荐 | 现有 consumption、推荐画像、首次使用服务 | 复用现有接口；同步来源、迁移备份及解释记录一并列明 |
| Ask Ryn 来源 | `ask-ryn/history.json`、来源恢复项 | 导出复用 `export_owner` 的允许字段；擦除使用上述原子步骤 |
| 会话同步副本 | `device-sync/replica.json` | 来源擦除提交后同步删除标记，清掉副本正文；失败保留待处理状态，不宣称完成 |
| 设备关系与远端结果 | `device-sync/pairings.json` | 邀请凭证、密钥不默认导出；离线、暂停、移除设备的旧副本不能宣称已收回；分别显示确认状态 |
| 迁移备份与中断写入副本 | 已知的 `.migrated`、`.v2.migrated` 及原子写入临时文件 | 明确列入审核，仅处理已核对路径和内容版本；中断后能重试，不递归删除整个用户目录 |
| 搜索派生数据 | `local-search/index.json` 及内存索引 | 来源清除后协调重建，等待正在执行的旧重建退出，防止旧快照重新落盘 |
| 旧浏览器会话 | `llmConversationStore.ts` 中的 IndexedDB/会话内存 | 当前浏览器清除单独确认；其他浏览器、浏览器备份不能由节点声称已删除 |
| 原始任务与结算 | `llm/consumer-orders`、结果保留接口 | 区分正文/结果与防重复结算记录；不得直接删目录导致任务身份或账务丢失 |
| 好友分享与导入内容 | `friends/state.json`、导入库 | 导出筛选公开关系字段，排除 secrets/邀请能力；清理独立保存副本与撤销关系分别说明 |
| 好友动态 | `friend-feed/state.json` | 草稿、发布快照、订阅和接收内容明确区分；停止相应后台接收后再清理 |
| 离线阅读 | `offline-reading/state.json`、下载目录 | 复用已审核的清理接口，包含正文、图片及检查点；旧下载任务不能重新写回 |

好友关系 `state.json` 是受私有文件权限保护的 JSON，不能将其描述为加密会话容器。其历史 `secrets.json` 及迁移备份也属于需要明确处理的凭证范围。

复用接口时还有两个已经核对的差别：

- 旧浏览器库实际为 IndexedDB `ryn-private-ai-chat`，包含 `keys` 和 `conversations`。当前 `deleteConversation`/`clearConversations` 捕获并忽略存储错误，不能直接作为已成功擦除的凭据；完整维护入口需要返回真实事务完成结果，并清除当前会话内存。节点导入后仍保留这些旧浏览器恢复副本。
- `TaskOrderStore.purge_encrypted_response` 能保留订单身份并删除持久化加密结果；`ConsumerCommands.acknowledge` 当前只移除标记为 ephemeral 的内存结果。完整清理须协调这两个范围及正在执行的后台任务，不能把 acknowledge 当成完整订单结果清除。

## 下一步协调流程

1. 在 Owner 设置入口显示导出/清除范围、数量及保留项，不默认导出密钥、邀请能力或 Provider 凭证。
2. 以一个稳定操作身份保存审核结果和分步进度。来源提交、副本清理、备份处理、索引和浏览器确认分别记录；部分失败保留重试入口，已完成步骤不重复清除新内容。
3. 遵守设备配对 → 来源 → 副本的现有锁顺序；索引重建和网络调用不得放在来源锁内，避免和读取来源的后台任务互相等待。
4. 验证端到端流程：审核后编辑、取消、磁盘失败、重启、旧消息、离线/移除设备、清除后再次使用。只有本地范围全部完成才显示本地完成；远端须另有真实确认。

## 节点清理协调接口

后续实现已接入完整节点的 Owner API，位于 `/api/local/privacy/conversations`：审核、创建清理操作、查看/继续进度、取消尚未提交的操作，以及重新审核发生变化的剩余备份。设置页尚未接入，以下为节点接口验证。

- 加密进度文件按来源 → 同步副本 → 已审核备份 → 搜索重建 → 订单结果记录完成步骤。失败保留已提交状态，重试不重新擦除之后创建的新会话。响应丢失时使用原操作身份查询/继续。
- 同步副本中独有的旧会话 ID 也列入审核。擦除不自动开启同步；以后启用时仍转换成永久删除标记，旧投递不能进入恢复区。
- 只删除来源 `.migrated` 和来源、同步副本、搜索索引的已审核原子临时文件。名称、位置、SHA256 都需匹配；其间新产生的副本不会被自动纳入。删除期间使用与索引、来源写入一致的锁顺序，避免清除仍在写入的文件。规范来源、阅读元数据与规范索引文件不作整目录删除。
- 备份内容变化时停止，重新审核当前剩余版本才继续。来源提交前失败的操作可取消，再生成新审核；已提交来源的操作不能冒充可撤销。
- 订单适配器同时清理已保存的加密结果和内存结果。磁盘终态不够：后台仍处于排队/执行/未知状态时继续等待。保留任务身份、状态与结算元数据；真实消费服务测试中余额保持一致、同一请求未再次派发。
- 返回的 `local_copies_complete` 只覆盖该操作审核过的节点副本。浏览器旧数据库仍明确为待清理，远端确认未在此接口中推断。未接入用户界面，不能据此标记完整验收通过。

相关来源/协调/权限/消费服务检查 **66 passed / 1 warning，6.67 秒**；再补完整节点实际依赖及原订单清理联调，**5 passed / 1 warning，1.70 秒**。订单新增测试首次因夹具跳过真实订单状态转换而失败，改为 created → accepted → running → succeeded 后通过，未放宽生产断言。Ruff 已通过。最终后端全量 **1308 passed / 29 skipped / 5 warnings，228.29 秒**，运行期间产品代码保持不变；本轮没有前端代码变更。

当前进度文件上限为 8 MiB / 32 项操作，每个来源最多审核 1024 个候选备份；达到限制会明确失败，不能靠丢弃删除标记或历史进度继续。后续设置页需要展示这些限制及处理入口。

完整导出下载、设置页、浏览器清理、其他数据范围及远端实测尚未完成，G08/SYNC13 状态不变。

## 设置页与旧浏览器副本

后续已在 Settings → Privacy & data 接入节点会话审核、确认、进度、原请求重试、继续清理、取消未提交操作和重新审核剩余备份。节点与浏览器操作分别确认，不推断远端成功。页面载入会读取已保存的节点进度；响应丢失时保留原审核身份，不创建另一个清理请求。

旧浏览器库升级为 IndexedDB v2，增加只保存删除标记和清理凭据的 `erasure` 存储；原 `keys` 和 `conversations` 数据不重写。审核绑定加密记录、当前标签页内存副本和清理修订。清理在同一 IndexedDB 事务中删除记录并保存标记，失败则回滚。旧身份不能在其他已加载模块或重启后再次保存；加密前和实际写入事务均检查标记，避免加密失败后退回内存而恢复旧内容。同一标签页的保存/擦除串行执行，其他标签页通过数据库事务与标记协调。

旧版标签页阻止升级时提示关闭后重试；未来清理格式不覆盖；损坏且无法解密的旧记录仍可审核清除。完成提示只涵盖该次审核的副本，不声称清除其他标签页中的开放视图、其他浏览器配置或远端设备。浏览器密钥保留，删除标记最多 10000 个，不能通过删除防重放记录来绕过限制。

实际浏览器验证见 [cleanup-settings-browser.json](cleanup-settings-browser.json)：审核、取消、键盘确认、结果焦点、节点重启、浏览器重载和再次导入均已执行。发现并修复了审核加载后和放弃审核后的焦点丢失；单独显示节点和浏览器范围，避免混淆完成状态。浏览器环境是隔离节点和合成数据，尚不代表完整产品验收。
