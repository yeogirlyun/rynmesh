- 界面首期仅使用英文，不增加语言切换或多语言系统；用户昵称、设备名、备注和已有聊天内容保留原文。技术信息折叠到高级设置。（按用户最新决定更新。）

1. 后端身份展示资料与本地备注存储、长度校验、迁移兼容；身份以现有 peer_id 为准。

3. 全部相关界面使用统一身份展示组件；短标识冲突时延长或提供完整指纹核对。
4. 将入口、邀请接续、服务审核、会话及权限管理接入现有机制。
5. 免费请求免重复弹窗仍需检查审核快照：接收方、服务、价格改变必须阻断并重新审核；拒绝偷偷切换模型。
6. 验证重启、改名、同名、迁移、邀请过期、安装接续、撤权与请求并发，构建 Windows 候选包。

## Mac 提供方试用与安装后检测

用户场景：提供方为韩国的 Apple Silicon Mac，已有模型但暂不清楚运行软件；接收方为用户的 Windows，双方不在同一局域网。不再把提前确认模型软件、模型名称或端口作为安装包交付前提。

- 使用同一 Apple Silicon 安装包，安装后在本机检测硬件、Ryn 已配置的 LLM 包和受支持的本地模型服务。
- 发现可用模型：展示检测结果，让用户选择复用，执行健康检查及一次真实回答自检；不重复下载。
- 没有发现可用服务：不能直接断言用户没有模型。提供重新检测、启动已有模型服务的提示，以及可选的一键安装推荐模型入口；本地 API 或 GGUF 导入放入高级选项。
- 一键安装复用现有硬件推荐、受管模型下载、运行时启动和自检能力；下载前展示大小和资源需求，由用户选择，不因检测失败自动下载。
- 成功后衔接好友 AI 授权与邀请；模型留在提供方 Mac 上运行，接收方无需安装模型。
- 现有基础包括 Ollama 模型发现、受管模型、GGUF 导入及 OpenAI 兼容本地 API 接入；不能据此声称已自动识别所有运行软件或所有磁盘模型文件。统一检测与引导仍需接入并验收。
- Mac 候选包需包含当前好友 AI 修复；另行完成 Mac 启动、已有模型接入、真实回答，以及韩国 Mac 到 Windows 的跨网调用验证。打包成功不等于跨网可用。
