## 三个公司插件

### Gshopper 公司工作台（company-workspace）

- Codex：统一账号身份、企微原生发送与账号校验；补齐聊天历史索引、搜索、分页读取、上下文查询、未读提及和媒体处理，兼容旧版会话数据库。
- Codex：插件工具按账号与授权隔离，发送提供操作状态和幂等处理；优化登录状态读取、历史缓存清理及 Windows 登录句柄探测。
- Claude：已保存会话列表立即显示；一次公司登录同步三个插件，并授权 Agent 读取企业微信历史；窗口重新获得焦点时保留插件页面。

### Dashboard（company-dashboard）

- Codex：接入原财务页面与中心身份验证；提供余额、日记账、审批搜索与详情、附件链接、库存、VAT、贷款及资金查询。
- Codex：补齐日记账导出、刷新操作与分页契约；金额及大整数精度保留，查询参数和权限校验完整。
- Codex：增加发货统计及统一日期筛选；支持 Agent 探索转账、导入、余额变动、销售预测与老板借款预览数据。
- Codex：修正历史周报现金流、贷款期间及汇率来源，补齐资金周报工具说明。
- Claude：增加资金周报逐页执行说明，完善 TPP 付款数据口径；按放款状态计算速卖通待结算款，时间字段按文本返回，并补充 Agent 使用说明。
- Claude：修复 OA 公司列表身份及 EPR/VAT 页面打开方式。

### 联盟营销（company-affiliate）

- Codex：交付联盟订单、佣金、提现、任务、内容、邮件、统计、用户中心及管理工作台源码。
- Codex：Dashboard 登录通过已有成员绑定访问联盟页面，统一账号状态与退出行为，保留独立业务权限。
- Claude：联盟插件纳入一次公司登录及多窗口状态同步，页面切换与焦点恢复保留已加载内容。
