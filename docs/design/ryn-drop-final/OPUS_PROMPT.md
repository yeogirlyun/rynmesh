必须保留的决定：

1. 不加顶层 Send。设备工作区只有「设备网络」「会话」「传输」三个页签。设备页以本机、局域网设备、互联网路径与远端设备的连接图为核心，保留首页现有网络总览。不要改成设备卡片墙，不要再出现大圆角框套小框。
2. 设备节点、离线设备和会话列表支持右键菜单，包含发送文件、发送文件夹、发送消息、传输记录、连接详情。保留「⋯」作为触屏入口。菜单正确绑定目标设备，支持窗口边缘避让、Esc、键盘导航和焦点恢复。会话列表右键其他设备不能偷偷改变当前草稿的收件端。
3. 节点可互发文字、链接、文件和目录。同一对设备共用会话，文件卡片与全局传输记录共用真实任务状态。网络路径自动选择，显示局域网直连、公网直连或中继。不能伪造在线、已送达、加密或完成状态。
4. LAN 和公网 P2P 直连均不设人为文件大小上限，100 GB 是必须支持的正常用例，不是新的上限。审计并修复引擎中的大小限制、整数偏移、流式 IO、分块校验、持久任务、断点续传和重启恢复；不要只移除前端校验。不能把大文件整体读入内存或 Base64 化。
5. 中继额度和约束单独处理。直连中断不能悄悄切成超限或付费传输。离线任务默认保留在发送端本机；未实现的离线云存储不在界面承诺。接收确认、空间检查、拒绝、取消、失败和重试按说明实现。
6. 首版不兼容 LocalSend，不做匿名公网分享链接或新离线托管服务。原生手机 App 后续开发，本次做好响应式和扩展接口，不将原型 iPhone 当成已发布能力。
