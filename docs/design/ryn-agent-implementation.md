# Ryn Agent 实现与验收记录

日期：2026-10-09。当前实现：模型管理场景的可运行版本；不代表通用 Agent 或“Claude Code / Codex 八成能力”已达标。

## 产品入口

- 左侧一级入口 **Ryn 助手**，路由 `/agent`。裸 `/ask` 跳转到这里；带资料、历史会话或指定节点参数的旧链接仍进入手动 AI 工作台并保留参数，旧历史入口保留。
- 独立工作区不包含服务页签、面包屑和大标题。主导航与任务列表可分别收起。
- **服务 → 模型** (`/services/sources`) 管理统一模型池。来源可包含多个模型，每个模型有独立分享状态。
- 首次默认关闭助手。验证模型的结构化工具调用及结果回传后，可设置助手默认模型，再启用助手。选择默认模型不会开启助手或改变分享。
- 未启用助手时，模型配置、普通推理、API 接入和对外分享仍可使用。

## 执行结构

`agent_runtime/runtime.py` 管理持久任务、模型/工具循环、上下文压缩及权限。`bridge.py` 复用已有本机服务与消费端 P2P 推理；`models.py` 提供无凭据模型目录；`tools.py` 对接真实业务；`store.py` 使用节点密钥加密持久状态。接口见 [API 契约](ryn-agent-api-contract.md)。

模型只能提出工具调用，工具由消费节点执行。提供模型的节点只处理当前推理请求，不附加自己的助手会话、工具或记忆。传输连接复用与保存 Agent 会话是两件事。远端推理仍会看到调用方主动发送的上下文与工具结果。

任务具有创建请求去重、修订号校验、暂停、继续、取消、审批、真实事件与结果。原始会话和证据完整加密保存；上下文摘要保留所有用户要求、真实修改回执及完整工具调用/结果配对。摘要不能赋予权限。

协议状态 `completed` 表示模型结束本轮，UI 对应“本轮结束”，不自动断言用户目标已达成；没有执行工具时明确提示。变更是否成功依据真实工具回执和随后读取的状态，不能只依据模型总结。

只读工具可直接执行；写操作按只读、逐次确认、显式工具白名单三种策略处理。自动白名单取任务创建时与当前设置的交集，新增权限不会追溯扩大旧任务。审批绑定参数、目标范围和配置版本，在业务锁内重新检查。明确未执行的拒绝可返回模型纠错；写入已发出但结果未知时，停止并要求核对，不自动重放。

## 已接业务工具

| 工具 | 实际能力 |
| --- | --- |
| `ryn_list_models` | 查看本机/来源/授权共享模型、能力与分享状态 |
| `ryn_list_devices` | 查看个人空间和好友设备，区分在线证据、过期证据及未知状态 |
| `ryn_inspect_services` | 查看模型服务及现有好友授权 |
| `ryn_set_model_sharing` | 修改一个自有来源模型或本地模型的个人空间分享，保留同来源其他模型状态 |
| `ryn_set_friend_model_access` | 对当前可向好友分享的服务，按授权修订号授予/撤销指定好友访问 |

来源凭据不会进入工具输出。对外广告在分享变更后刷新，最后一个分享撤销时发布空清单；协调服务不可用时明确记录发布待完成，本机准入立即按新设置判断。

## 模型兼容范围

- OpenAI 兼容 Chat Completions 来源：逐模型显式验证工具请求与结果回传，普通文本连通测试不推断工具能力。
- 已配置的 Codex CLI：使用现有客户端工具协议，但须通过当前二进制的显式两轮工具验证，不能仅凭 CLI 已安装、聊天成功或协议字段存在就标为可用。
- Claude CLI 的现有接入是文本对话能力，不能直接用作 Ryn 工具主控。
- 本地托管模型：显式验证能力，模型配置变更后旧证据失效。
- 对方分享的模型：只使用对方发布的结构化工具能力和现有访问权限；执行权仍在本机。
- 工具验证不等于流式验证。未知来源可使用完整响应；请求流式却返回 JSON 时消费同一响应，不重复请求、不伪造增量输出。

## 参考与复用边界

参考 Codex、Claude Code 的官方机制资料和 ZCode 已核对的公开源码结构，落实循环、上下文、事件与权限分层。ZCode 阅读清单和固定版本见 [模型池设计 v3](ryn-model-pool-agent-v3.md)。本次运行时是适配 Ryn Python 节点的实现，没有声称移植三者完整产品或使用泄露代码。

## 验收方法与边界

自动测试覆盖完整“读取 → 审批 → 修改 → 再读取”业务闭环、多个调用方会话隔离、逐模型分享、能力探测、权限撤销、参数篡改、配置竞争、重启、中途取消、未知写入结果、长上下文及流式兼容。另用隔离节点和确定性本机 HTTP 模型测试生产构建的浏览器页面，未改变用户运行节点。除此之外，使用本机已有的 Codex 登录完成了下述兼容性测试，未输出凭据或更改登录设置。

最终验证：前端 560 项全量测试通过、类型检查及构建通过；后端 259 项相关回归通过（4 项跳过），最后权限修复后运行时/业务集成/后台任务 87 项复测通过。截图和实际流程见 [验收记录](../acceptance/ryn-agent-20261009/README.md)。

本轮尚未提供通用 Shell/整机操作、网盘批量文件操作、自定义 Skills 管理、跨任务长期偏好记忆或子 Agent 协作。当前上下文保存和压缩属于单任务能力。没有进行系统性的商业模型效果评测、跨物理机器稳定性测试或桌面安装包发布，因此不能据此宣称达到“八成水平”。

真实已登录 Codex CLI 的隔离只读试验发现：聊天自检成功，但当前环境隔离模式下模型报告工具环境被禁用，未实际调用工具。因此增加显式验证门槛；不为兼容模型而开放提供节点的 Shell、文件、插件或宿主工具。此发现不能被模拟上游测试通过所替代。

任务预算默认 16 次模型调用、180 秒活跃处理时间；摘要也消耗调用预算。确认等待时间不计入。现有限定为最多 200 个持久任务、24 MiB 解密状态；长期归档管理仍需后续扩展。
