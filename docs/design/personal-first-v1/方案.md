# Ryn 个人优先改版方案
日期：2026-09-21 · 状态：设计提案，未实现或接入真实服务。

**定位：先连接自己的电脑，再把服务分享给其他节点。**
沿用当前 Rynmesh 的节点和服务基础，调整首页、导航与交互；个人使用是起点，节点互联与对外提供服务继续保留。

## 页面有几个

**5 个主要页面 + 1 个 AI 使用子页 + 3 类弹窗。**
另外保留原有「内容探索」「聊天」两个二级入口，本轮不重画其内部页面。
因此一级/二级导航页面共 7 个；服务下的业务子页单独计算，不继续增加主导航。

| 页面 | 用户来做什么 | 核心区域 | 设计图 |
|---|---|---|---|
| 我的空间（默认首页） | 快速使用自己的电脑能力 | 设备、备注、常用服务、连接摘要 | [01](01-home.png) |
| 服务 | 使用能力或提供自己的能力 | 来源筛选、服务列表、API 接入、开启服务 | [02](02-services.png) |
| 节点 | 管理连接关系与权限 | 我的设备/其他节点、名称备注、双向授权 | [03](03-nodes.png) |
| 任务 | 跟踪跨设备工作的进度和结果 | 我发起的/我处理的、状态、下载、取消 | [04](04-tasks.png) |
| 设置 | 配置当前设备的应用偏好 | 外观、启动与后台、连接诊断、数据隐私 | [05](05-settings.png) |
| 私人 AI（服务子页） | 与选定节点上的模型对话 | 来源节点、模型、会话、API 接入 | [06](06-private-ai.png) |
| 编辑节点（弹窗） | 修改名称、别名和备注 | 自己/他人两种权限状态 | [07](07-node-edit.png) |
| 添加设备、分享服务（两类弹窗） | 配对电脑、开放指定能力 | 配对码、对端确认、服务与节点选择 | [08](08-pair-share.png) |

「我的空间」是快捷入口；「节点」负责完整管理，二者使用同一份节点数据。
「聊天」保留为人与人聊天；「私人 AI」是服务子页，两者分开。
已有其他服务工具从服务页进入；API 接入使用子面板，不另加主导航。

## 名称与备注

- 自己的节点：可编辑对外名称（1–32 字）和私人备注（0–200 字）。
- 别人的节点：保留对方名称，可设置本地别名（0–32 字）和私人备注（0–200 字）。
- 名称去除首尾空白后不能为空；别名、备注可清空。别名为空时显示对方名称。
- 备注默认只存本机，不随服务发布；跨自己的设备同步作为后续明确选择，不默认承诺。
- 自己的节点改名须在该节点确认所有权/控制权限后执行；“已配对”不等于自动获得管理权。
- 名称可以重复，内部始终使用稳定节点 ID；改名不影响连接、任务或授权。
- 首页、服务来源、节点列表、任务来源均使用一致的名称解析规则；备注长文折叠，详情显示全文。
- 备注只是文字说明，不自动设置共享时段、唤醒电脑或改变权限。

## 第一阶段流程

1. 两台电脑安装 Ryn，在「我的空间 → 添加设备」配对并完成双方确认。
2. 家里电脑开启模型服务，笔记本在自己的设备中看到它。
3. 点击「使用」进入私人 AI，始终显示正在使用的节点与模型。
4. 如需给别人使用，在「分享服务」中选择具体服务和接收节点；可分别撤销。
5. 耗时任务在「任务」中查看执行位置、状态及结果。

配对码短时有效、一次使用，过期可重新生成；图中 000 000 仅为示例。
提供者离线时保留节点、禁用调用并提供重连；AI 不静默切换到其他节点。
任务取消先进入「取消中」，收到执行节点确认后才显示「已取消」。
服务页明确「自己的设备/其他节点」来源，开启服务默认针对本机；远端管理必须验证所有权。
自己使用自己的服务不应受开发余额约束；资源并发与限额仍需管理。
授权按“服务 × 接收节点”记录；断开当前连接与撤销长期授权为两个动作。

## UI 统一规则

- 台式机统一显示器图标，不带机箱；笔记本使用笔记本图标。
- 同类型节点不靠不同造型区分，靠名称、备注和状态区分。
- AI 使用星芒图标；文档和节点图标保持相同尺寸、圆角和视觉重量。
- 所有页面与弹窗提供浅色、深色和跟随系统；状态同时有文字，不只依赖颜色。
- 图中的橙色编号是评审标注，不进入正式 UI。
- 图像为概念稿，细微字体、图标、颜色和文案差异在实现时按统一组件收敛。
- 文档转换、语音服务为扩展示例，不代表已经实现；首期优先验收远端 AI。
- 设置图把各分组同时展示用于评审；实际可用单页分组锚点，不应让“外观”选项隐藏其他设置却仍显示其内容。

## 开发顺序

1. 首页和节点：设备类型、名称备注、配对、在线/离线状态。
2. 服务闭环：模型使用、API 接入、服务授权与撤销；验证两台真实电脑跨网使用。
3. 任务与设置：完善进度、取消、错误恢复、后台和统一主题。
4. 在同一节点体系下继续扩展好友服务和非 AI 能力。

保留现有代码与功能，先实现新版入口并逐步迁移；本轮没有修改业务代码或部署。
