# 做图 1.0.0

Ryn 的独立公开做图插件。页面、队列与作品存储在安装者电脑运行，通过本机登录的 Codex 出图。

需要带公开插件运行接口 `host_api = 1` 的 Ryn，以及本机 Codex。安装后默认不开放给其他人；现有公司通道用户可在“管理任务与分享”中开启分享。

完整说明：[Ryn 公开插件与私有插件](../../docs/PUBLIC_AND_PRIVATE_PLUGINS.md)。

数据继续使用 `<Ryn 数据目录>/image-studio/`，更新、停用和卸载保留作品。插件不是独立 Python 开发环境安装教程，普通用户应从 Ryn 插件页安装签名发布包。
