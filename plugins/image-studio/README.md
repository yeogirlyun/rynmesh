# 做图 1.1.0

做图是 Ryn 的公开插件，使用提供方电脑上已登录的 Codex 生成图片。需要支持公开插件接口 `host_api = 1` 的 Ryn。从「应用 → 发现」安装签名包，在应用详情中使用做图、管理队列和分享。新安装时共享开关默认关闭，启用后，同事可以在「应用 → 同事共享」打开。

## 新建作品

1. 选择横幅、商品主图、海报、详情页头图或社媒配图。每个场景提供常用尺寸，也可自定义宽高。例如，横幅支持 1920 × 600 和 1200 × 400。
2. 上传、拖入、粘贴图片，或点击「从素材库选」，每次最多五张。「素材」用于保留商品外观，「风格参考」用于参考配色、构图和氛围。两种角色可以混用。
3. 按需填写主标题、副标题和角标，选择风格、尺寸和张数。图片、文案和补充说明至少提供一项。要把商品单独用于其它设计，可勾选「透明底」，完成后下载 PNG。

## 复用素材与作品

上传后点「存到素材库」，填写名称，选择商品、Logo 或风格图。素材库可按名称或类型搜索。每人可管理自己的私有素材，主人还可以添加、删除公共素材。同事可在任务中选用公共素材。

在完成作品的详情页，可以勾选最多六个其它尺寸批量生成，或选择「只换背景」「只改文字」「换个角度」并补充要求。「只改文字」会带入原来的三栏文案。派生作品的「来自原图」链接可返回原图。

数据保存在 `<Ryn 数据目录>/image-studio/`，更新、停用和卸载保留作品与素材。接口字段、队列限制和保留时间见[做图接口说明](../../docs/IMAGE_STUDIO.md)。安装与共享范围见[公开插件与私有插件](../../docs/PUBLIC_AND_PRIVATE_PLUGINS.md)。
