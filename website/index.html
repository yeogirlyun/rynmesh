A node, not a cloud account

The local daemon is the authority.

Identity, preferences, feedback, and fetched content live beneath the owner’s RynMesh home. Network and model access are optional capabilities mediated by the node.

Read the architecture
01

Local-first

The personal-assistant experience works without joining a peer network.

02

Open implementation

The node, interface, protocol, registry, tools, and recommendation agent are MIT licensed.

03

Explicit boundaries

Cloud model access requires configuration; the web interface does not bypass the node.

04

Receipts over promises

Signed manifests, provenance, and safety evidence are designed to be inspected locally.
