Help build RynMesh.

RynMesh is an MIT-licensed, local-first personal AI app and a friend-to-friend content mesh, built in public by a very small team. Everything is in one repository: the Python node, the React web app, the Tauri desktop shell, the protocol and the docs. Pick accepted work from the live backlog, reserve it with /claim, ship a pull request, and CI plus a maintainer review verify it.

What we are building toward

Read first, then pick.

Four milestones, in order: a companion that is useful alone, a trusted circle of friends, services and an agent with limits, and only then an open network. v0.7.0 shipped milestone 1 and the first half of milestone 2. These documents explain the design, the current state, and how work is verified.
