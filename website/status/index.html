Transparent roadmap

Build the companion first. Add trusted friends next.

The roadmap separates released behavior from active hardening and later network ambitions. Accepted engineering work remains traceable to public GitHub issues.

Milestone 1

Ryn Companion

The local personal-assistant foundation exists. Current work is reliability, explainability, content-viewer hardening, test coverage, and platform portability.

Alpha hardening

Local node and desktop app

Self-hosted daemon, bundled interface, local identity and state, Apple Silicon and Intel macOS packages.

Zero-configuration recommendations

Built-in public discovery, direction, preferences, evidence, and feedback-driven local ranking.

Personal-assistant critical path

Component tests, per-source recovery, learned-signal explanations, and feedback undo are accepted contribution work.

Content and contract hardening

Daily Digest consolidation plus accessible, privacy-reviewed document and media handling require approved designs.

Desktop portability

A verified first Linux desktop package is open for contribution; Windows packaging is a separate later item.

Milestone 2

Trusted Friends

A small, intentional group should become more useful than isolated personal nodes without weakening owner control.

Planned
01

Invitations

Explicitly invite and revoke trusted friends rather than exposing a node to arbitrary discovery.

02

Friend-attributed discovery

Understand which trusted relationship contributed an item and why it reached the owner.

03

Private collaboration

Share content and useful services under owner-selected policies and auditable receipts.

Milestone 3

Open RynMesh network

Broader discovery and services arrive only after identity, abuse resistance, privacy, safety, and economic rules are hardened.

Later milestone

No speculative value promise

Current RynMesh Credits are non-transferable reputation signals. The project does not represent them as money, an investment, or a guaranteed future asset.
